# Dr. Jawaria Rasheed — Clinic Website (WordPress)

Website for **Dr. Jawaria Rasheed, Consultant Gynecologist & IUI Specialist**.
It is built with WordPress, the free **Astra** theme and free **Elementor**. Page content can be edited visually in Elementor.

> Status: **Phase 1 — local build.** Not live yet. Medical text is a draft that Dr. Jawaria needs to review (see `docs/content-checklist.md`).

## What's in this folder

| Path | What it is |
|---|---|
| `wp-content/themes/jawaria-child/` | Child theme of Astra: colours, fonts, top bar, footer (design system in `assets/css/site.css`) |
| `wp-content/plugins/jawaria-clinic/` | Clinic toolkit plugin: **Settings → Clinic Info**, **Appointments** (request form + records), WhatsApp button, shortcodes, and **Tools → Clinic Site Setup** (creates all pages and menus in one click) |
| `wp-content/plugins/jawaria-clinic/content/` | Page layouts (Elementor JSON) and draft articles, generated by `tools/build.py` |
| `tools/` | Python scripts that write the page text and layouts (`content_services.py`, `content_posts.py`, `build.py`) |
| `preview/` | Static design preview. Open `preview/index.html` in a browser; WordPress isn't needed |
| `docs/` | Content checklist and editing guide |

## Run it on your computer (LocalWP)

1. Install **LocalWP** (free): https://localwp.com. Create a new site, for example **jawaria** (address `jawaria.local`), using the "Preferred" environment. Note the admin username and password you choose.
2. In the site's WordPress admin:
   - **Appearance → Themes → Add New:** install **Astra** (installing is enough; you don't need to activate it).
   - **Plugins → Add New:** install and activate **Elementor**.
3. Link this folder's theme and plugin into the Local site. Open **Command Prompt as Administrator** and run the two commands below. If your Local site isn't named `jawaria`, change that part of the path.
   ```bat
   mklink /J "%USERPROFILE%\Local Sites\jawaria\app\public\wp-content\themes\jawaria-child" "D:\Dr. Jawaria Rasheed\Jawaria Rasheed Website\wp-content\themes\jawaria-child"
   mklink /J "%USERPROFILE%\Local Sites\jawaria\app\public\wp-content\plugins\jawaria-clinic" "D:\Dr. Jawaria Rasheed\Jawaria Rasheed Website\wp-content\plugins\jawaria-clinic"
   ```
   These are links, so the site always uses the files in this folder (the ones that go to GitHub). If you'd rather not use links, copy the two folders into the same places instead.
4. **Appearance → Themes:** activate **Jawaria Rasheed Clinic**.
   **Plugins:** activate **Jawaria Clinic Toolkit**.
5. **Settings → Clinic Info:** add the phone, WhatsApp, address, timings and qualifications. You can also do this later, and every page updates automatically.
6. **Tools → Clinic Site Setup → "Create website pages & menus".** This creates:
   - Home, About, Services plus 12 service pages, Patient Reviews, Videos, FAQs, Contact, Book an Appointment, Health Articles (blog), Privacy Policy and Medical Disclaimer
   - the main menu and footer menu, the home page and blog settings, and clean URLs
   - 3 draft health articles (in **Posts → Drafts**, to review before publishing)
7. Visit `http://jawaria.local`.

## Day-to-day editing

- **Page text and images:** open the page, click **Edit with Elementor**, click any text or image, change it, then **Update**.
- **Phone, WhatsApp, address, timings:** **Settings → Clinic Info** (one place updates the whole site).
- **Add a new service:** **Pages → Add New**, set **Parent = Services**, write a short **Excerpt**, and publish. It appears automatically on the Services page and the booking form. The quickest way is to duplicate an existing service page in Elementor.
- **Logo:** **Appearance → Customize → Site Identity → Logo** (replaces the "JR" badge in the header).
- **Menus:** **Appearance → Menus** — "Header – top row", "Header – services row" (add the CSS class `jr-mega` to a top item to show its sub-items as a 3-column mega menu), "Footer – Our Services", "Footer – Quick Links".
- **Patient reviews:** **Patient Reviews → Add New** — only shown when "patient gave permission" is ticked.
- **Videos, highlight numbers, Google rating, social links:** **Settings → Clinic Info**.
- **Appointment requests:** the **Appointments** menu. Phone and WhatsApp links are built in, so call the patient and then set the **Status** to *Confirmed* with the date and time.

## Everything is managed in WordPress

| What | Where in WordPress |
|---|---|
| Page text, images, sections | Pages → Edit with Elementor |
| Add or remove a service page | Pages → Add New (Parent: Services) |
| Blog articles | Posts → Add New |
| Phone, WhatsApp, address, timings, areas served, social links, videos, highlight numbers | Settings → Clinic Info |
| Header and footer menus | Appearance → Menus |
| Logo and site icon | Appearance → Customize → Site Identity |
| Appointment requests | Appointments |
| Patient reviews | Patient Reviews |
| Home page banner slider (images, headings, buttons, order) | **Home Slides** (speed: Settings → Clinic Info) |
| SEO titles and descriptions | Rank Math box under each page |

## Before going live (Phase 1 finish)

On the live site, install **Rank Math SEO**, **Wordfence**, **UpdraftPlus** (backups) and the caching plugin your host supports (**LiteSpeed Cache** on LiteSpeed hosts). Work through the checklist in `docs/content-checklist.md`.

## Rebuilding page content

After editing the text in `tools/*.py`:
```bash
python tools/build.py
```
Then run **Tools → Clinic Site Setup** again with **Overwrite** ticked. Be careful: this replaces any edits made to those pages in Elementor.
